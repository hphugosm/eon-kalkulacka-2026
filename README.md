Samostatný `index.html` funguje v prohlížeči i offline po stažení. Bez serveru, externích knihoven či přihlášení.

- Ekonomické přecenění 51 uložených konfigurací: CAPEX, provoz, obnovy, diskont a zůstatky.

- Neúplné emise a trilema zůstávají výslovně nehodnocené. Ceny jsou modelové předpoklady, nikoliv dodavatelské nabídky.
- Export konfigurace, porovnání a cash flow do JSON/CSV.
